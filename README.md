# Скалодром «Зацеп»

Учебный проект: веб-приложение из трёх контейнеров, поднимается через docker compose.

Приложение ведёт учёт трасс на скалодроме: какие трассы сейчас накручены, в каком секторе, какой категории и цвета зацепок, кто их пролез и каким стилем. По пролазам считается рейтинг скалолазов.

## Контейнеры

| Сервис   | Что внутри                           | Порт на компьютере |
|----------|--------------------------------------|--------------------|
| frontend | nginx, страница на HTML/CSS/JS       | 8080               |
| backend  | Python 3.12, FastAPI                 | 8000               |
| db       | PostgreSQL 16, данные из db/init.sql | 5432               |

Браузер ходит только во frontend. Запросы на /api/ nginx пересылает в контейнер backend, а backend ходит в db по имени сервиса внутри сети docker compose.

## Запуск

Нужен запущенный Docker Desktop. В папке проекта:

```
docker compose up --build
```

Открыть http://localhost:8080

Документация API (Swagger): http://localhost:8000/docs

Остановить: Ctrl+C или `docker compose down`.
Сбросить базу к исходным данным: `docker compose down -v`, затем снова `up`.

## Что умеет фронт

1. Трассы на стене: список активных трасс, фильтр по сектору. Клик по трассе показывает, кто её пролез.
2. Что полезть сегодня: случайная трасса в выбранном диапазоне категорий.
3. Свежая накрутка: трассы, накрученные за последние 3, 7 или 14 дней.
4. Рейтинг: очки за пролазы за 30 дней. Очки зависят от категории, онсайт даёт ×1.5, флэш ×1.25.
5. Категории: сколько трасс и пролазов на каждой категории.
6. Отметить пролаз: запись в БД (POST). Новый скалолаз создаётся автоматически.

## Структура БД

grades (категории и очки), sectors (секторы стены), routes (трассы), climbers (скалолазы), ascents (пролазы).

## API

| Метод | Путь                         | Что делает                     |
|-------|------------------------------|--------------------------------|
| GET   | /api/health                  | проверка связи с БД            |
| GET   | /api/sectors                 | секторы и число трасс в них    |
| GET   | /api/routes?sector_id=       | активные трассы                |
| GET   | /api/routes/random           | случайная трасса в диапазоне   |
| GET   | /api/routes/fresh?days=      | свежая накрутка                |
| GET   | /api/routes/{id}/ascents     | пролазы трассы                 |
| GET   | /api/leaderboard?days=       | рейтинг скалолазов             |
| GET   | /api/stats/grades            | статистика по категориям       |
| POST  | /api/ascents                 | добавить пролаз                |
